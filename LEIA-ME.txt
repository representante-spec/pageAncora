Versão SEM a logo Anatote

PARA O SITE (Render)
  Crie um Static Site no Render com o nome  ancora-consorcios  (gera
  https://ancora-consorcios.onrender.com) e suba TUDO desta pasta na raiz do
  repositório. Branch main · Build Command: echo "static" · Publish: .
  index.html ...... versão web do e-mail (página inicial)
  cadastro.html ... formulário de cadastro
  assets/ ......... imagens
  Se o endereço for outro, os links e as imagens do e-mail precisam
  ser trocados (ancora-consorcios.onrender.com).

PARA O MARKETING (ferramenta de disparo)
  email-para-envio.html – colar como "HTML personalizado". Imagens em
  https://ancora-consorcios.onrender.com/assets/ e botões levando para
  https://ancora-consorcios.onrender.com/cadastro.html
  utm_source=email · utm_medium=email · utm_campaign=representante-ancora
  · utm_content = botão clicado (padrão do formulário: categoria-auto)
